## 📚 项目简介

本仓库是一个完整的信息学竞赛（Olympiad in Informatics）学习资源库，旨在帮助中学生系统地学习算法和数据结构，为参加NOIP、NOI等信息学竞赛做好准备。

## 🎯 项目特色

- ✅ **系统化学习路径**：从入门到进阶的完整知识体系
- 📝 **详细的竞赛流程指南**：报名、备考、参赛全流程
- 💻 **精选编程题目**：包含详细题解和多语言实现
- 🎓 **实战经验分享**：竞赛策略和技巧
- 🔄 **持续更新**：不断添加新的题目和知识点

## 🚀 快速开始

### 1. 了解竞赛流程
首先阅读 [信息学竞赛流程.md](信息学竞赛流程.md)，了解：
- 竞赛体系和级别
- 学习路线和知识点
- 报名流程和考试形式
- 备考策略和资源推荐

### 2. 开始刷题
进入 [problems](problems/) 目录，按照难度循序渐进：
- **入门级**：问题1 - 两数之和
- **中等级**：问题2 - 二叉树遍历
- **中等偏难**：问题3 - 最长公共子序列

### 3. 学习建议
- 每天坚持练习1-2小时
- 先理解题意，再思考算法
- 独立完成代码实现
- 对照参考答案优化

## 🎓 学习路径

### 第一阶段：基础入门（1-3个月）
- [ ] 学习C++/Python基础语法
- [ ] 掌握基本输入输出
- [ ] 完成入门级题目（如问题1）
- [ ] 学习基础算法：枚举、模拟、贪心

### 第二阶段：进阶提高（3-6个月）
- [ ] 学习常用数据结构：栈、队列、树
- [ ] 掌握经典算法：递归、分治、二分
- [ ] 完成中等难度题目（如问题2）
- [ ] 参加线上模拟赛

### 第三阶段：高级进阶（6个月以上）
- [ ] 深入学习动态规划（如问题3）
- [ ] 掌握图论算法
- [ ] 学习高级数据结构
- [ ] 准备参加NOIP/NOI

## 🔧 环境配置

### C++ 开发环境
```bash
# Linux/Mac
sudo apt-get install g++  # Ubuntu/Debian
brew install gcc          # Mac

# 编译运行
g++ -o solution solution.cpp -std=c++11
./solution
```

### Python 开发环境
```bash
# 安装Python 3
python3 --version

# 运行程序
python3 solution.py
```
